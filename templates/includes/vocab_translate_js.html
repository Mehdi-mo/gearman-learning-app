The server renders every phrase it already knows, so on most pages this script finds nothing to do and makes no request at all. What it does find is marked `.tr-pending`, carries the English in `data-src`, and shows a small spinner until its own language arrives. If the request fails or the daily limit is used up, the element falls back to the English rather than spinning forever. {% endcomment %}
